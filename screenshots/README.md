# App Screenshots

Screenshots of myFamily app features and workflows.

## Folder Structure

- **auth/** - Login, signup, family join workflows
- **dashboard/** - Home dashboard, activity feed, quick actions
- **medicines/** - Medicine management, scanning, reminders
- **appointments/** - Appointment scheduling, calendar, details
- **messages/** - Family messaging, voice messages, notifications
- **settings/** - Profile, family settings, accessibility options
- **accessibility/** - Voice control, large text, contrast modes

## Naming Convention

Use format: `FEATURE_ACTION_STATE.png`

Examples:
- `medicines_list_idle.png`
- `medicines_scan_result.png`
- `appointments_add_modal.png`
- `messages_voice_recording.png`
- `dashboard_mom_account.png`

## How to Capture

1. Run app with mock data enabled
2. Log in with test account
3. Navigate to feature
4. Take screenshot at key states (idle, loading, success, error)
5. Save with naming convention
6. Add to appropriate folder
